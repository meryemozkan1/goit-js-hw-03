# GoIT JavaScript Homework #3 (Module 3)

This project is the third JavaScript homework assignment within the GoIT Full Stack Developer program. It focuses on working with arrays, fundamental array methods (`concat`, `slice`, `push`), `for...of` loops, and string-to-slug transformation algorithms.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-js-hw-03/)

## 🛠️ Tasks Included
- **Task 1:** `slugify` — Converts a article title into a readable URL slug format in lowercase separated by hyphens.
- **Task 2:** `makeArray` — Combines two arrays and limits the resulting array length based on `maxLength`.
- **Task 3:** `filterArray` — Filters numbers from an array that are strictly greater than a given threshold value using a `for...of` loop.

## 🛠️ Technologies & Tools Used
- **JavaScript (ES6+):** Arrays, iteration loops, string manipulation methods.
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
